# IBM Bob Task Session Reports

This folder contains the mandatory evidence of interaction with **IBM Bob IDE** as required by the hackathon submission guidelines (pages 18-19 of the Guide).

## 📁 Required Artifacts per Session:
1. **Exported Task History**: A `.md` file exported directly from the Bob IDE history panel.
2. **Consumption Screenshot**: A screenshot of the task header showing token usage and Bobcoin consumption.

## 🚀 How to populate this folder:
1. Open this project in **IBM Bob IDE**.
2. Perform development tasks (Refactoring, Explanation, Testing).
3. In the Bob Chat, click **... (Views and More Actions)** -> **History**.
4. Select a meaningful task session.
5. Click the **Export** icon to download the Markdown file and save it here.
6. Take a screenshot of the **Task Consumption Summary** and save it here (e.g., `session_1_usage.png`).

---
*Note: Ensure all credentials/API keys are removed from the exported files before pushing to a public repository.*
